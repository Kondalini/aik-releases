
**AIK** is an AI automation platform for small and mid-size businesses: AI agents that read
e-mail, process invoices and documents, answer phone calls, browse websites, work with
databases and post to social media, on a schedule and with a person's approval before
anything is sent or changed.

It runs in our cloud or **on your own server**, so your data can stay in your building.
Every result AIK produces is marked as AI-generated, and every action is written to a
tamper-evident log.

🌐 Website: https://aikautomation.com
📖 User guide: https://aikautomation.com/docs.html
🔒 Security brief: https://aikautomation.com/security.html

## What is in this repository

Signed release packages for AIK installations. An installed AIK checks here and updates
itself when you press *Check for updates*; every package is verified with a digital
signature before it is applied.

This repository does not contain the source code.
